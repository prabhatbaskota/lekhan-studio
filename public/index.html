How the typing works

Type in lowercase roman letters at word-end (space, punctuation, enter), and the word converts to Devanagari automatically. Long vowels double up: aa, ii/ee, uu/oo.

Devanagari has no letter case, so this tool borrows CAPITALS for sounds English spelling can't tell apart. Don't capitalize names or sentence starts out of habit. Only use capitals for the sounds below.

Retroflex vs dental

T D N → ट ड ण   vs   t d n → त द न

Sibilants

S → ष   sh → श   s → स

Vocalic R (ऋ)

Natural spelling usually just works for common words: rishi → ऋषि, kripayaa → कृपया. For anything else, capital R alone (no extra i) gives the ऋ sound directly: RSi → ऋषि.

Anusvara / Visarga

* → ं   ** → ँ   e.g. s*saar → संसार
(M / H / ~ still work too)

Formal vs informal names

Capitals control which spelling you get: ganesh→गनेश, gaNesh→गणेश (canonical)

Two consonants wrongly joining

By default, back-to-back consonants conjunct: raajkumaar → राज्कुमार (wrong). Type the vowel between them instead: raajakumaar → राजकुमार ✓

A truly "dead" consonant

For the rarer case of a consonant with no vowel at all (usually word-final), type _ right after it: sat → सत, but sat_ → सत्

Sentence-ending punctuation

A single . becomes । (purnabiram). Type three dots for an ellipsis and they stay .... A period right after a digit is treated as a decimal point instead, so 2.5 → २.५.

ञ (nya)

Standalone yn gives ञ directly: yoynjan → योञ्जन, vyaynjan → व्यञ्जन. (Different from jn → ज्ञ, which is the reverse-order conjunct used in ज्ञान.)

Keep a word (or phrase) in English

Wrap it in curly braces to skip conversion entirely: {USB-C}, {CEO}, {Sundar Pichai}, {www.example.com}.

Examples

hamlaai maayaa cha → हामीलाई माया छ

About this Nepali Unicode typing tool

लेखन Studio is a free online Nepali Unicode typing and converter tool built for writers, bloggers, and content creators. Type Nepali phonetically using Roman/English letters, and it converts automatically to clean Devanagari Unicode text. No separate software or Preeti font conversion needed. It also includes Nepali text-to-speech narration, so you can listen to what you've written.

How do I type Nepali online without a Nepali keyboard?

You don't need a Nepali keyboard installed on your computer or phone. Just start typing a word phonetically in Roman letters (e.g. "namaste") in the box above, and it converts to Devanagari (नमस्ते) the moment you hit space or punctuation. See the Typing Guide button above for the full set of conventions, including tricky sounds like ऋ, ष, and ञ.

Is this a Preeti to Unicode converter?

Not currently. लेखन Studio converts phonetic Roman typing (like "namaste") directly to Unicode Devanagari. A Preeti font converter mode is planned but not yet available.

Does this work as a Nepali Unicode font converter?

लेखन Studio outputs standard Unicode Devanagari text, which displays correctly everywhere, including Facebook, WhatsApp, Word, and websites, without needing any special Nepali font installed on the reader's device.

Can I convert Nepali text to speech (audio)?

Yes. लेखन Studio includes Nepali text-to-speech narration with both male and female voice options. Type or write your Nepali text, click Listen to hear it read aloud, and download the audio if you want to keep it.

Is this Nepali Unicode converter free?

Yes, लेखन Studio is completely free to use, with no sign-up required.
